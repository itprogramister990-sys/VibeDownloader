## 🎯 Overview

**VibeDownloader** is a sleek media downloader interface built with Next.js 14 and TailwindCSS. Clean UI, minimal friction, maximum clarity.

---

## ✨ Features

- 🔗 **Paste & Go** — Drop a URL and instantly see download options
- 🎞️ **Format Selection** — Choose quality and format before downloading
- 🌙 **Dark Mode UI** — Easy on the eyes
- ⚡ **Instant Feedback** — Smooth progress indicators
- 📱 **Responsive** — Works on mobile and desktop

---

## 🚀 Running Locally

```bash
git clone https://github.com/itprogramister990-sys/VibeDownloader.git
cd VibeDownloader
npm install
npm run dev
# Open http://localhost:3000
```
